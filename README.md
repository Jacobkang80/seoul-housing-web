# 서울 청약·주거 모니터

GitHub Pages에서 제공하는 독립 HTML 대시보드입니다. 스마트폰·태블릿 브라우저에서 홈 화면에 추가할 수 있습니다. GPT·LLM·데이터 API 인증키 없이 실행합니다.

- 8개 구 전용 84.00㎡ 이상~85.00㎡ 미만 아파트의 월별 평균 매매·순수 전세 실거래 금액(억원), 전월 대비 등락률과 최근 10년 그래프.
- 한국 시간 07:15·12:15·18:15에 공식 공개자료 수집 후 같은 웹주소에 배포합니다. 예약 실행은 GitHub 상황에 따라 지연될 수 있습니다.
- 수집 실패 시 마지막 유효 자료와 기준 시각을 유지하고 화면에 갱신 미완료를 표시합니다.
- 홈 화면 앱은 온라인 접속 시 새 자료를 읽고, 오프라인에서는 마지막 저장 자료를 표시합니다.
- 매매가 25억원 미만·지하철/셔틀 도보 조건 필터. 현재 실제 판매 매물 및 이용 가능한 셔틀 정류장 공급원은 미연결입니다.
- 청약은 SH·LH 공개 공고 후보 목록 감시입니다. 민간분양·무순위 전체 확정 접수일 수집은 미완료입니다.

공개 화면·공개 통계자료·해당 자료 수집 코드만 보관합니다. 개인 이름·계정 인증정보·Google Sheets 링크를 포함하지 않습니다.

## 출처와 해석

서울부동산정보광장 연간 매매·당해 전세 XLS, 서울 열린데이터광장 과거 전월세 ZIP. 매매는 취소거래 및 분양권·입주권을 제외하고, 전세는 월 임대료 0인 계약을 포함합니다. 계약월 거래금액 합계 ÷ 건수 ÷ 10,000 = 평균 금액(억원)입니다. 거래 단지·층·연식 구성에 따른 평균 변화이며 호가·고정 구성 가격지수와 구분합니다. 최신월은 신고 지연으로 수정될 수 있습니다.
